
# JavaScript Trivia CLI Game

## Description
A command-line trivia game built with JavaScript and Node.js.

## Features
- Interactive multiple-choice questions
- Immediate feedback on answers
- Score tracking
- Countdown timer for each question
- Overall game time limit
- Final score and performance feedback

## Requirements
- Node.js
- Ubuntu/WSL or another terminal

## How to Run
1. Open the project directory in your terminal.
2. Run `node index.js`.
3. Type `START` to begin the quiz.
4. Select answers by entering the option number.
